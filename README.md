# ПРИП — Белое, Баренцево и Печорское море

Действующие ПРИП (прибрежные предупреждения) на карте и в файлах для штурманских программ.
Источник — сайт ФГБУ «Администрация морских портов Западной Арктики» [mapm.ru](https://www.mapm.ru):
ПРИП Архангельск, ПРИП Мурманск и ПРИП Запад (из него — только Печорское море и проливы
Карские Ворота и Югорский Шар).

**🗺 Карта онлайн, обновляется каждый час: https://kubiqq.github.io/PRIP/**

**⬇ Программа для Windows: [последний выпуск](https://github.com/kubiqq/PRIP/releases/latest)**

## Возможности

- На карту попадают только номера из официального списка «ДЕЙСТВУЮЩИЕ ПРИП … НА …».
- Координаты из текста ПРИП превращаются в объекты: точки (буи, знаки, опасности), районы,
  окружности («радиусом 500 метров»), границы «между берегом и линией».
- Учитываются частичные отмены («ОТМ 32/26 ПУНКТ 4») и срок отмены («ОТМ ЭТОТ НР 302100 СЕНТ»).
- Категории: стрельбы и запретные районы, опасности, работы, навигационное оборудование.
- Файлы: `prip_timezero.gpx` (TimeZero), `prip.gpx` (OpenCPN, картплоттеры), `prip.kml`
  (Google Earth), `prip.geojson`. Скачать свежие можно по ссылкам в шапке онлайн-карты.

## ПРИП-Синхро для TimeZero Navigator

`PRIP-Sync.exe` — программа для Windows 10, Python не нужен. При запуске загружает ПРИП,
показывает, что изменилось с последнего обновления TimeZero, и готовит файл для импорта.

- **Полная замена** (рекомендуется): удалить в TimeZero все объекты «ПРИП …» и импортировать
  `prip_timezero.gpx`.
- **Только изменения**: импортировать `prip_timezero_new.gpx` с новыми ПРИП и удалить
  отменённые по именам, которые покажет программа.
- Без связи показывает последние сохранённые данные и их возраст.

Подробности — в `Инструкция.txt` в выпуске.

## Запуск из исходников

Нужен Python 3.8+, сторонние библиотеки не требуются.

```bash
python prip_update.py          # карта и файлы в папку out/
python prip_sync.py            # окно ПРИП-Синхро
```

Сборка exe (нужен `pip install pyinstaller`):

```bash
python -m PyInstaller --onefile --windowed --name PRIP-Sync --version-file version_info.txt --add-data "map_template.html;." --add-data "vendor;vendor" prip_sync.py
```

## Важно

Это не официальный источник навигационной информации. Контуры районов строятся автоматически
по тексту ПРИП; там, где в тексте «далее по береговой линии», граница упрощена.
Решения при плавании принимайте по полному тексту ПРИП и официальным картам.
